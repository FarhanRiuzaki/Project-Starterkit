# Backlog SunnyGo

Diperbarui 8 November 2026, Sesi 1 Product Lead. Target: **template siap dipakai lokal**, sesuai konfirmasi pemilik. Urutan di bawah menentukan prioritas kerja, bukan janji kalender. Satu owner role bertanggung jawab atas setiap tugas. Sesi sunny-designer, sunny-developer dan sunny-qa teridentifikasi melalui inventory; nama individu/kapasitas belum ditetapkan. Developer mencakup BE dan FE.

P0 = menghalangi penerimaan/rilis lokal atau keamanan/data; P1 = perlu untuk kesiapan MVP; P2 = tahap berikutnya atau peningkatan non-blocking. Ready = input dan AC cukup untuk mulai; Conditional = tunggu hasil dependency; Blocked = dependency/informasi wajib belum tersedia. Effort adalah hari fokus role owner, tidak termasuk waktu tunggu. Target D1 dst mengikuti skenario kapasitas di [product](product.md#milestone-dan-perkiraan-timeline).
